# AGENTS.md — OrbitLink

## 01 - Contexto

OrbitLink é uma rede social espacial para a Global Solution — Indústria Espacial.

## 02 - Regras do projeto

01 - Código em pt-BR.  
02 - Variáveis, funções, componentes e comentários em pt-BR.  
03 - Usar React + Vite + TypeScript + Tailwind.  
04 - Não usar pasta `features` nesta versão.  
05 - Componentes separados por responsabilidade.  
06 - Manter comentários delimitadores por bloco.  
07 - Manter o app funcional mesmo se APIs externas falharem.  
08 - Manter fallback local/simulado.

## 03 - Entrega atual

Fase 01 com:

01 - DualView AR simulado.  
02 - Feed social.  
03 - Posts com texto e imagem.  
04 - Status Orbital 24h.  
05 - Galeria.  
06 - Perfis.  
07 - Missões.  
08 - Painel NASA com EONET, EPIC e Image Library.  
09 - Tema dark/light inspirado nas referências enviadas.

## 04 - Validação obrigatória

Antes de entregar qualquer ZIP:

01 - `npm install`  
02 - `npm run dev`  
03 - teste HTTP local  
04 - `npm run build`
